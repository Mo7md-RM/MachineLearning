# Lab 2 – Machine Learning Problem Identification

## Dataset Information
- Dataset Name: BMW Used Cars Dataset
- File Name: bmw.csv
- Number of Rows: 10781
- Number of Columns: 9

## Features
- model
- year
- price
- transmission
- mileage
- fuelType
- tax
- mpg
- engineSize

## Machine Learning Problem
This dataset aims to predict the selling price of a used BMW car based on its characteristics such as model, year, mileage, transmission type, fuel type, engine size, mpg, and tax.

This is a Regression problem because the target variable (price) is numerical.

## Target Variable
price

## Goal
To build a machine learning model that predicts the price of a BMW used car.
